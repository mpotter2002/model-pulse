Model Pulse Privacy Policy

Last updated: August 11, 2026

Model Pulse helps you view your own AI-provider usage, limits, and spend. The app has no user accounts and does not operate a Model Pulse server.

Permission before provider sharing

Before Model Pulse sends personal data to an AI provider, the app presents an in-app disclosure and asks for your affirmative permission. You may decline. In Settings, Stop & remove access withdraws permission, stops future provider requests, and removes saved provider credentials and cached usage data from this device.

Data stored on your device

  • API keys, admin keys, OAuth access and refresh tokens, authorization codes, account IDs, and OAuth scopes that you enter or approve.
  • Provider account telemetry, including plan name, usage and quota windows, reset times, token and request totals, account balance, organization spend, and rate-limit information.
  • App preferences, optional monthly budgets, widget configuration, and local alert thresholds.

Credentials are stored with iOS Keychain through Expo SecureStore. Preferences and cached usage are stored locally. Model Pulse does not receive or store this data on a developer-operated server.

Direct sharing with providers

After you grant permission, Model Pulse sends data directly from your device to the provider you choose. Depending on the connection method, this consists of an API key, admin key, OAuth access or refresh token, OAuth authorization code, and the request needed to obtain account telemetry. The provider returns that telemetry so Model Pulse can show it in the app and Home Screen widget and, if enabled, evaluate local usage alerts.

Possible recipients are OpenAI/ChatGPT, Anthropic/Claude, Moonshot/Kimi, MiniMax, Z.ai, Google/Gemini, ElevenLabs, Poe, Codebuff, GitHub/Copilot, Chutes, Factory, and OpenCode.

Model Pulse does not send chat prompts, chat responses, files, contacts, analytics identifiers, advertising identifiers, or data to a Model Pulse server. The selected provider's handling of data it receives is governed by that provider's own terms and privacy policy.

Other uses and disclosures

Model Pulse does not use personal data for advertising, cross-app tracking, marketing, sale, profiling, or analytics. It includes no advertising or analytics SDKs and does not share personal data with any party other than the provider you select and approve.

Data deletion

You can remove an individual subscription connection from its model screen or an API key from its provider screen. Stop & remove access in Settings removes all saved provider credentials and cached provider usage from the device. Deleting the app removes remaining app data stored by the app.
