# Model Pulse Privacy Policy

Last updated: August 11, 2026

Model Pulse ("the app") helps you view your own AI-provider usage, limits,
and spend. Model Pulse has no user accounts and does not operate a Model
Pulse server.

## Permission before provider sharing

Before Model Pulse sends personal data to an AI provider, the app presents an
in-app disclosure and asks for your affirmative permission. The disclosure
explains the data sent, names the providers that may receive it, explains why
it is sent, and links to this policy.

You may decline. You can also withdraw permission at any time in Settings by
selecting **Stop & remove access**. That stops future provider requests and
removes the provider credentials and cached usage data held by Model Pulse on
your device.

## Data the app collects and stores locally

When you choose to connect a provider, Model Pulse may collect and store on
your device:

- API keys, admin keys, OAuth access tokens, OAuth refresh tokens, OAuth
  authorization codes, account IDs, and OAuth scope information that you
  enter or approve.
- Account telemetry returned by the selected provider, including plan name,
  usage and quota windows, reset times, token and request totals, account
  balance, organization spend, and rate-limit information.
- App preferences you set, such as display settings, provider order, optional
  monthly budgets, widget configuration, and local alert thresholds.

Credentials are stored using iOS Keychain through Expo SecureStore. Preferences
and cached usage are stored locally on the device. Model Pulse does not receive
or store your data on a developer-operated server.

## Direct sharing with AI providers

After you grant permission, Model Pulse sends data directly from your device
to the provider you choose to connect. Depending on the connection method,
this consists of an API key, admin key, OAuth access or refresh token, OAuth
authorization code, and the request needed to obtain account telemetry. The
provider returns the telemetry described above so Model Pulse can show it in
the app and Home Screen widget and, if enabled, evaluate local usage alerts.

The possible recipients are:

- OpenAI / ChatGPT
- Anthropic / Claude
- Moonshot / Kimi
- MiniMax
- Z.ai
- Google / Gemini
- ElevenLabs
- Poe
- Codebuff
- GitHub / Copilot
- Chutes
- Factory
- OpenCode

Model Pulse does not send chat prompts, chat responses, files, contacts,
analytics identifiers, advertising identifiers, or data to a Model Pulse
server. The selected provider's handling of data it receives is governed by
that provider's own terms and privacy policy. Model Pulse only sends data to
the provider the user explicitly chooses and has approved.

## Other uses and disclosures

Model Pulse does not use personal data for advertising, cross-app tracking,
marketing, sale, profiling, or analytics. It does not include advertising or
analytics SDKs. It does not share personal data with any party other than the
provider you select and approve.

## Data deletion

You can remove an individual subscription connection from its model screen or
an API key from its provider screen. **Stop & remove access** in Settings
removes all saved provider credentials and cached provider usage from the
device. Deleting the app removes remaining app data stored by the app.
